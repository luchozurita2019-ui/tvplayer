PROVEEDOR 2 - JSON DE PRUEBA

Pegá aquí el JSON REAL que entrega el proveedor, reemplazando el contenido de:
assets/provider_json/proveedor_2.json

No hace falta modificar ningún otro archivo.

Cuando esté cargado, se implementará el resolver para conservar y resolver:
- URL del stream
- tipo de stream (HLS/DASH/MPD/etc.)
- MIME
- headers
- User-Agent
- Referer/Origin
- ClearKey
- keyId/KID
- licenseUri
- CENC/DRM
- demás metadatos presentes en el JSON

Esta carpeta es de prueba y queda separada de las listas M3U/Xtream actuales.
